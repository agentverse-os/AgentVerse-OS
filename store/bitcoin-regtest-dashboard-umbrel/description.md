A self-contained development dashboard with its own Bitcoin Core regtest node and Electrs instance. No external dependencies required.

Features include:
  - Mine blocks instantly with one click
  - Auto-mine blocks until stopped or for a set duration
  - Generate new addresses (all types supported)
  - Send Bitcoin to any address
  - View and manage UTXOs
  - RBF (Replace-By-Fee) transactions
  - Cancel unconfirmed transactions
  - Browse mempool and blocks
  - Decode and broadcast raw transactions
  - Full RPC console for advanced commands


Perfect for Bitcoin developers who need quick access to regtest node functionality for testing wallets, applications, and Bitcoin integrations.
