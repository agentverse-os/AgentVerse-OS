💬 Lobe Hub is a self-hosted AI workspace for conversations, agent teams, knowledge bases, and multimodal workflows.

🗣️ It supports speech, multimodal chat, files, knowledge retrieval, and a rich provider ecosystem including OpenAI-compatible APIs, Anthropic, Google, Groq, Ollama, and more.

🤖 This Umbrel package now follows the current upstream self-hosted deployment model and includes PostgreSQL, Redis, and S3-compatible object storage for uploads and knowledge base features.

🔑 To get started, create an account on first launch and then add one or more AI provider API keys in the Lobe Hub settings.
